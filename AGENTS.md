# Study Hub — mandatory revision authoring skill

Applies to every subject for Grace and Adel, every update, including quizzes, model answers, revision notes, matching exercises and mock exams.

## 1. Source and scope
- Read all supplied school pages, images, revision lists and linked resources before drafting. Identify the pupil's year group, subject, assessment scope and actual command words.
- Separate printed teacher material from pupil handwriting. The latter may identify misconceptions, but must never be treated as an answer key.
- Map every question to a specific school topic and a revision note. Never invent a syllabus, exam format, teacher instruction, source, statistic, quotation or required fact.
- If the supplied material is a question-technique guide rather than lesson notes, state that limitation. Use only directly relevant, age-appropriate explanatory examples, independently verify them, clearly label them as examples, and teach them in the notes before assessing them. Do not claim these were taught at school. Avoid testing unprovided factual minutiae (e.g. dates, verse numbers) as recall requirements.
- If linked sources cannot be opened, disclose that. Do not silently substitute a broader syllabus.

## 2. Educational value
- Test subject knowledge, application, reasoning, and exam-answer construction. Do NOT ask pupils to remember booklet wording, which examples a pupil wrote, marks assigned to a worksheet question, slide numbers, page numbers, or other administrative trivia.
- Exam technique belongs in concise notes, scaffolds, and authentic written practice, not filler quiz questions. Applied questions on evaluating an actual argument or developing an actual point are valid.
- Use age-appropriate UK English, progressive difficulty, genuine variations, plausible distractors, and a mixture of multiple choice, matching and free text. Each multiple-choice item must have precisely one defensible best answer; ensure the stem contains enough context. Never present a religious belief or opinion as a universally established fact.
- Accept all valid alternatives for open questions; never restrict a model to the pupil's original answer. For evaluation accept well-reasoned different conclusions. Do not reward mere repetition of keywords or personal beliefs.
- Keep relevant highlighted terms limited to key knowledge. Do not add unrelated topics to reach an arbitrary question count.

## 3. Verification gate before any publish
- Review EVERY question, all choices, keyed answer, rationale, hint, linked revision note, matching pair, and written model against the actual source and year group.
- For each item ask: Is it on the supplied topic? Does it teach or assess something useful? Is the answer correct? Are all distractors clearly incorrect in context? Is it taught in the notes? Is it age-appropriate? Could another answer also be valid? If any check fails, rewrite or remove the item.
- Verify supplemental factual claims and religious quotations/teachings using authoritative sources; preserve source links and distinguish illustrative material. Do not fabricate evidence or require the child to memorise a supplement unless supplied by school.
- Check correct-answer mappings after shuffle, no duplicate options, question and mark counts, all source references, and that every written marking criterion matches the question. Label indicative self-assessment clearly; never pass it off as an official school mark scheme or automatic essay marking.
- Validate script syntax and run functional browser tests when available (navigation, every level, wrong-answer review, free-text submission, scoring, progress persistence). Distinguish checks actually run from checks not run. Preserve relevant progress; invalidate obsolete question-specific results when questions change.
- Confirm the repository commit and subject link; provide a cache-busting revision link when updated. Do not claim live deployment or device tests without checking.
- Publish only after the content audit. Report source limitations and the checks actually completed.
